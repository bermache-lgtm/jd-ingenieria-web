# JD Ingeniería & Proyectos S.A.C. — Sitio web

Sitio web de JD Ingeniería & Proyectos S.A.C., División Pesaje (Lima, Perú).

## Páginas
- `index.html` — Inicio
- `nosotros.html` — Nosotros
- `servicios.html` — Servicios
- `productos.html` — Productos
- `proyectos.html` — Proyectos
- `contacto.html` — Contacto

## Estructura
```
index.html, nosotros.html, servicios.html, productos.html, proyectos.html, contacto.html
assets/site.css   estilos
assets/site.js    animaciones, menú, galería y formulario
img/              fotos y logos (img/prod: productos)
```

Sitio estático en HTML, CSS y JavaScript, sin dependencias ni compilación.

## Publicar con GitHub Pages
1. Sube estos archivos a la raíz del repositorio.
2. En el repositorio entra a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
4. En uno o dos minutos la web queda en `https://<usuario>.github.io/<repositorio>/`.
